# bus002 Octop 接入 nx5 双模型

> 当前版本已改为仅MiniCPM常驻，工具调用复用单槽前缀缓存，空闲保留GPU租约。下文10分钟结果属于旧版每请求加载的基线；当前运行语义见[调用手册](nx5-service/API.md)。


## 使用

打开 [Octop](http://bus002.taild500c8.ts.net:8088)，使用原有账号登录。
在聊天输入框的模型选择器中选择 `nx5-local` 下的模型：

| 显示名称 | API 模型 ID | 总上下文 | 单轮输出上限 |
|---|---|---:|---:|
| NX5 · Qwen3.6 35B-A3B · 128K | `qwen36-128k` | 131072 | 7680 |
| NX5 · MiniCPM-V4.7 35B-A3B · 64K | `minicpm-64k` | 65536 | 7680 |

思考默认开启，模型控件可切换。普通任务使用思考；标准鹈鹕对照测试关闭思考，并使用 AGENTS.md 中的原文。
模型声明输出能力为7680；Octop代理未指定 `max_tokens` 时网关默认2048，思考和答案共用额度。
如长任务出现输出截断，在代理模型参数中将 `max_tokens` 设为7680以内。

模型可以产生函数工具调用，由 **Octop 在它自己的运行环境中执行工具**，再将结果交给模型继续回答。
执行权限仍受 Octop 的 ask/plan/craft 模式及工具审批控制。网关不会在 nx5 执行模型生成的命令。
不支持通过此 API 上传图片；MiniCPM 的模型原生视觉能力不代表本接口已经提供视觉输入。

原有 `siyuan-nx6` 连接和模型列表保留。用户随后要求改用 MiniCPM，已将 Octop 全局默认模型切为
`nx5-local/minicpm-64k`；Qwen 保留可选，原有服务仍可手动选择。

## 可复现配置

- [无密钥模型配置](../deploy/octop/nx5-provider.json)
- [配置更新脚本](../scripts/octop/configure-provider.py)：从私有 `auth.json` 获取 Octop 登录态，通过 SSH 读取 nx5 专用令牌；更新指定连接，并检查原有连接及全局默认模型未变。
- [Octop真实任务验收](../scripts/octop/verify-task.cjs)：创建新测试会话，通过实际WebSocket入口调用 `current_time`；记录工具结果、思考字符数及最终答案。
- [工具往返验收](../scripts/octop/verify-tools.py)：在 Octop 容器内使用实际安装的 `octop_harness` 与 LangChain 客户端运行；私有 provider JSON 从 stdin 输入，不打印凭据。
- [品牌页面修复脚本](../scripts/octop/fix-branding-importmap.py)：校验原HTML的SHA，备份后添加import map，保持Docker单文件bind mount的inode。

`reasoning_config.adapter="dashscope"` 在当前 Octop 中表示发送 `enable_thinking` 布尔参数的适配方式，
不改变供应商连接、路由或模型所在地；请求仍只发送到 nx5。
`stream_usage=true` 让 Octop 收到实际token用量。

工具协议支持 `auto`、`none`、`required` 和指定函数；支持流式工具参数、函数结果回传、思考字段及真实usage。
底层命令行以 `--no-escape` 读取JSON，避免工具参数的嵌套引号被二次解码。
预处理期间每5秒发送空 `delta:{}` 心跳；普通SSE注释会被SDK过滤，无法重置其120秒分块超时。
旧版本Octop实测曾因此断流后自动重试、撞上互斥槽位返回429；修复保持连接，不伪造思考、答案或usage。
协议、限制和示例以 [API手册](nx5-service/API.md) 为准。

## 加载与耗时

两个模型、OpenWebUI与原有异步任务共用一个准入槽位；并发请求会返回429，不会强杀另一个模型。
模型每次请求加载、完成后卸载并释放中央租约，SSD保存全部专家，内存只保留缓存窗口。
工具执行期间模型已释放；工具结果回传会产生下一次模型加载和完整历史预处理。
因此多步任务会比单轮聊天慢，不能用纯生成TPS直接推算总耗时。

固定的小型加法工具测试，思考开启、每轮上限512 token：

| 模型 | 调用工具并完成最终回答 | 工具参数 | 最终答案 |
|---|---:|---|---|
| Qwen3.6 | 89.4秒（两轮） | `a=17,b=23` | `40` |
| MiniCPM | 60.2秒（两轮） | `a=17,b=23` | `40` |

这是实际 Octop 客户端库的短提示测试，包含加载和预处理；Octop完整代理会附加系统提示和工具说明，耗时更长。
每次测试结束均确认模型卸载、租约释放。原始记录见 [工具测试日志](../reports/2026-10-22-octop-tools/langchain-tools.log)。
